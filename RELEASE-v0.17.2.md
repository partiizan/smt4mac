# SMT4Mac v0.17.2 — Upwell names on hover

- Removed the Facilities button and its separate regional browser.
- Hover over a system to see each known Upwell structure's name and type, including structures resolved through the optional ESI connection.
- Tooltip details are available even when facility map markers are switched off.
- Selected-system details and the Structure ESI connection remain available.
- Unknown structures cannot be listed; public coverage remains incomplete.
