# SMT4Mac v0.17.3

The macOS application menu uses SMT4Mac. The Apple Silicon download no longer includes the v0.10 notes.

Ansiblex CSV imports now reject empty or comment-only files without replacing the current network. The status shows how many imported links have both endpoints on the selected regional map. Edit the file, save, and import again.

The Upwell feed releases its raw response after processing. Idle memory savings have not yet been measured on a Mac.
